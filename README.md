# AI Writing Assistant Suggestions

This example demonstrates how AI can act as an active writing partner, moving beyond simple text generation. It takes user input and provides suggestions for elaboration, rephrasing, or expansion. This simulates an AI co-pilot to enhance a writer's creativity and productivity, aligning with the article's concept of AI as an 'iş ortağı' (business partner).

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal using `python main.py`.
Enter your text when prompted to receive AI-powered suggestions.
